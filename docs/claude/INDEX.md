# docs/claude

Procedures and traps that need more than a few lines, each linked from the rule in a `CLAUDE.md` that needs it. A guide earns a place here only when a task has steps the code doesn't make obvious, or a trap that has cost a session real time; undocumented beats noise, so anything the code, a test name or an existing guide already says stays out. Each guide gives the symptom, the cause and the rule, then the procedure, the traps, and what the gates still won't tell you.

Read a guide when its trigger matches what you are about to do.

| File | When to read |
|---|---|
| [`adding-a-core-method.md`](adding-a-core-method.md) | Adding or changing a `core.Core` method — pick its kind (the line comment in `core/iface.go`), forward it from the loop, regenerate the wire, give a local query a view method and parity cases, keep a `ReqID` top-level, rewrite the protocol reference, bump `rpc.Protocol` only on removal or renaming; traps: the model's query and its view method are two implementations, a `time.Time` loses its monotonic reading, only three errors survive `errors.Is` |
| [`adding-a-core-event.md`](adding-a-core-event.md) | Adding a `core.Event` — list it in `EventTypes()`, give an error field a wire form, a state event a coalescing key, an event naming a request its `forConn` route, and the TUI an applier; traps: `wireCore`'s reseed hides a missing applier, synchronous test clients hide ordering, a cast publishes nothing, an event with no client connected is lost unless it is a `Notice` |
| [`changing-the-instance-schema.md`](changing-the-instance-schema.md) | Changing a persisted `session.InstanceData` field — carry it both ways, bump `CurrentSchemaVersion`, add the `Migrate` step, update the `workspace migrate` mirror and its fixture; traps: downgrade safety, `workspace migrate` drops a newer record's unknown fields, a change of meaning without a bump, fields that must survive `Recoverable` adoption |
| [`adding-a-gated-job.md`](adding-a-gated-job.md) | Adding throttled background work to the model — a `gateKind` and its `gateIntervals` entry, a dispatcher whose builder returns nil when there is nothing to do, the `Deliver` case, a case in `TestProductionGatedJobsYieldOneResult`; traps: arming without dispatching latches the job off, one result per job, a hung subprocess holds the gate, stale answers, results landing after the instance moved |
| [`adding-an-enforce-test.md`](adding-an-enforce-test.md) | A written rule was broken again — turn it into a source scan: find the root by depth, skip `vendor/` and dot-dirs, resolve aliased imports per file, pin the matcher with a detection table, mark the rule Enforced; traps: committed fixtures trip every walker, never plant a violation in a worktree, `go test -overlay` is invisible to scans, no type information |
| [`adding-a-modal-state.md`](adding-a-modal-state.md) | Adding a full-screen `m.state` — menu-highlighting exclusion list ("toy"→"oyt"), `View()` overlay placement list (invisible modal), `handleKeyPress` routing, background messages still land |
| [`launch-options.md`](launch-options.md) | Adding or changing a launch option or the composed command line — classify it, then config, `launch.Options`, the adapters, both overlays, the `R` flow, the model and the wire; traps: inserting a row renumbers index-driven tests, `--model` asserts are input or output, old programs decode forever, rewrite indexed assertions bottom-up |
| [`releasing.md`](releasing.md) | Cutting a release — bump `version` in `main.go`, prepend a scoped `git cliff --prepend` section, cross-build for Windows; traps: a full regeneration merges releases when tags lag, the release notes share that blind spot, a Unix-only call passes CI and breaks the release, no Go change means no release |
| [`testing-pitfalls.md`](testing-pitfalls.md) | Writing fakes, fixtures or guard tests, or proving a regression test goes red — fakes sharing the bug's geometry, fixtures skipping production's start step, both sides of a guard, mutation per guard term, copy-freshness tests, `-overlay` keys and scans, the worktree's `git add -N` index trap, probing a Claude premise live |
| [`nix-build-failures.md`](nix-build-failures.md) | A test passes locally but fails in the Nix build, CI or under load — no TZ, locale, `$TMUX` or `.git` in the sandbox, the check phase stopping at the first failing package, unpaced real-tmux output redrawn as one screen, 108-byte socket paths, a busy-loop load repro |
| [`debugging-freezes.md`](debugging-freezes.md) | The TUI or the daemon stops responding — detach first, TUI or daemon, `wchan` fingerprints, a goroutine dump by SIGQUIT to a stderr file, the known stuck-goroutine signatures (`Send` under a lock, a call from inside a loop call); traps: one dump per repro, a hand-made driver's first paint |
| [`incident-triage.md`](incident-triage.md) | Sessions died together, a session won't resume, pause or die, or a worktree is gutted — tell an external kill from load's false deaths from a half-removed worktree by the logs before touching anything; traps: a gutted dir answers git for the main repo, the worktree-add reflog entries are harmless, a raw `git worktree add` registers nothing with loom, an older installed loom lacks the guards |
| [`ui-geometry.md`](ui-geometry.md) | Sizing bordered boxes or mapping mouse cells — lipgloss Width/Height include the border and Height is a minimum, SGR resets drop backgrounds, runewidth tail, HitTest offsets (topChromeHeight), selection gated to stateDefault+stateInlineAttach, drags never forwarded |
| [`auditing-claude-md-currency.md`](auditing-claude-md-currency.md) | After a big refactor, a deletion, a retired concept or a long merge, or on a schedule — triage `claudemd -idents` findings (ELSEWHERE, missing, negative claim), re-check Enforced claims, re-count lists and range ends, check CI claims, compare tokens when moving text; traps: zsh word splitting, compressed git and grep output, large outputs |
