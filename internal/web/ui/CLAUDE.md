# internal/web/ui

The web layer's new app, for the phone and, from 1024px wide, the desktop: its source is here (React, TypeScript, Vite, Tailwind and shadcn on Base UI), `pnpm run build` writes it into `internal/web/dist/`, which the daemon embeds and serves to a device that chose it, and the classic app in `internal/web/static/` stays beside it until cutover.

## Rules when modifying this app

- **Never edit `internal/web/dist/` or `internal/web/ui/src/api/gen.ts` by hand; rebuild with `pnpm run build` and regenerate with `go generate ./internal/web`, and commit the result with the source change.** The bundle is what the daemon serves and `gen.ts` is the Go contract's TypeScript, so a hand edit is overwritten by the next build, and a source change committed without its bundle ships the old app. **Enforced** by `pnpm run dist:check` (CI's `.github/workflows/web.yml`, the step "Bundle is fresh") for the bundle and by `TestContract_GeneratedFilesAreFresh` for `gen.ts`.
- **Add a view only as a panel and an action only as a command.** A panel (`definePanel`, `internal/web/ui/src/app/panels.ts`) is imported from `internal/web/ui/src/panels/index.ts` and given its URL in `routeOf` and `hrefFor` (`internal/web/ui/src/app/routes.tsx`); a command (`defineCommand`, `internal/web/ui/src/app/commands.ts`) is drawn by `CommandButton`. The registries give every view its tab and error boundary and every action its confirmation, toast and stale gate; a view or button wired by hand skips them and acts on a stale fleet. **Convention** — a button that acts on a snapshot the daemon has since changed.
- **A command's `when` reads only the session's status and group, its `claude` flag, the route and the link state, and only an `offline` command runs while the snapshot is stale.** The model decides what is allowed and a wrong guess is its 409, shown as a toast; `group` is read because only it tells a Recoverable or unstarted Ready session from a started Ready, as the classic actions do; a copied precondition drifts, then offers what the daemon refuses or hides what it allows. Only `app.backToClassic`, `device.pair` and the palette's two view toggles, `view.toggleSidebar` and `view.toggleInspector`, are `offline`, because the switch must work with the daemon down, pairing runs before any snapshot exists and a toggle changes only this browser's layout. **Enforced** for the stale gate by `internal/web/ui/src/app/commands.test.ts` and for the toggles by the case `a toggle runs while the snapshot is stale` in `internal/web/ui/src/commands/view.test.ts`; what `when` reads is **Convention** — a button that does nothing, or an action missing.
- **Set `palette` on a command only when it takes no args, and never on one whose args a view picks (an ask's answer, a job's controls, a send).** The palette lists exactly the registered commands that set the mark and runs one through `runCommand` with the route's context and no args, so a command that reads its args would run with `undefined` and fail or act on nothing. **Enforced** for the set by the cases `the palette lists exactly these ten commands` and `no command that takes args sets the mark` in `internal/web/ui/src/commands/palette.test.ts`; marking a new no-args command is **Convention** — a command the palette never lists.
- **Write no runtime `<style>`, no `style` attribute as markup and no HTML built from a string, and draw Claude's text from its tree (`blocks`) as elements and text nodes.** The Content-Security-Policy is `default-src 'self'`: it drops an injected style or inline attribute without a word, and a string put into the page renders whatever markup Claude's text holds. React's `style` prop is not a `style` attribute, since it sets the property through the CSSOM, which the policy allows, so a bar's computed width or height (`Bars` in `internal/web/ui/src/panels/flow/parts.tsx` and the cost box's and the flows list's bars, which take exact percentages) goes through the prop, never through a `style=` string in markup and never through one class per step. Import a component's CSS statically and keep `main.tsx`'s Base UI `CSPProvider` with `disableStyleElements`. **Enforced** for the shell by `TestStatic_NextIndexHasNoInlineScriptOrStyle` and for a violation at run time by webshot under the real policy (CI's `.github/workflows/web.yml`, the step "Render every route"); the rest is **Convention** — a view that is blank or unstyled only on the phone.
- **Take every colour and font from the tokens in `internal/web/ui/src/styles/app.css`, and keep form text at 16px, touch targets at 44px (written in px: `min-h-[44px]`) and the safe-area insets.** The skin is dark only, its tokens arranged so a light set drops in as a second block of the same names, and iOS zooms into a form control under 16px; `html` sets 13px, so a rem class like `min-h-11` is 35.75px, short of 44. **Enforced** for the tokens by `TestDist_TheSkinDefinesEveryToken`, which reads the built CSS; using a token rather than a literal, and the phone sizes, are **Convention** — a skin that cannot be re-themed, a page that zooms on focus.
- **Keep the first load within `firstLoadBudget`: load a screen the first view does not need (the flow views, job, mockup, new session, settings, the desktop shell) through a dynamic `import()`, so it builds into a chunk of its own.** `internal/web/static_budget_test.go` sums the gzipped entry script and every `modulepreload` that `internal/web/dist/index.html` names, and a heavier bundle slows every launch on a phone. **Enforced** by `TestDist_FirstLoadIsWithinBudget`.
- **Make a view the first load does not need a panel whose `Body` is `React.lazy` over a module of its own, keep its `Head` in the entry, and let `PanelHost` draw it under its `Suspense`.** A view imported statically lands in the entry script and slows every launch on a phone, and a lazy `Head` leaves the header empty until its chunk loads; the job view (`internal/web/ui/src/panels/job/JobBody.tsx`) is the pattern, and the conversation, info, changes and subagent views and pairing stay in the entry because a push opens the conversation and an unpaired launch opens pairing. **Enforced** for the chunks `checkLazyViews` lists (`JobBody`, `MockupBody`, `FlowBody`, `FlowStoryBody`, `FlowDocBody`, `FlowsBody`, `NewSessionBody`, `SettingsBody`, `FlowBoardBody` and `DesktopShell`, the desktop shell: a lazy frame, not a panel's Body, so the phone's first load is unchanged), to which a new lazy view adds its stem, by `TestDist_LazyViewsAreChunksOfTheirOwn` (`internal/web/static_budget_test.go`); another view imported statically is held only by `TestDist_FirstLoadIsWithinBudget` — a heavier launch until the budget fails.
- **Take the type of every JSON shape the daemon sends from `gen.ts`, and never write one by hand.** A hand-written copy drifts from the Go struct and the app then reads a field that is gone with no error; the generated type fails the typecheck instead. **Enforced** for the fixtures by `internal/web/ui/src/fixtures.test.ts`, which holds each `tools/webshot/fixture` answer to its route's generated type; a hand-written copy is **Convention** — a screen that renders empty after a Go change.
- **Read the daemon from a view only through `internal/web/ui/src/api/reads.ts`, never with a `fetch` or an `api.<client>` call that sends a request from a component of its own; `api.mockupURL`, which only builds a URL, is not one.** The module holds the classic app's refresh rules and its caches in the query cache: one request in flight with a load asked meanwhile run once it lands, no retry (the next poll is the next attempt), the pages and scroll of the last 8 conversations and the logs of the last 5 jobs kept, and an unpair clears them through `queryClient.clear()`; a read a component writes itself refetches on every mount, polls without those rules and keeps a stranger's pages after an unpair. **Enforced** for the rules by `internal/web/ui/src/api/reads.test.ts`; that a component reads only through the module is **Convention** — a screen that polls twice or shows another account's turns.
- **Draw Open in Claude, and every other link that acts on nothing in loom, as a plain `<a>`, never as a command.** Such a link (`claude ↗` in `internal/web/ui/src/session/SessionHead.tsx`, the needs-you box's Open in Claude) changes no state, so it needs no confirmation, in-flight key or stale gate, and a window opened after a command's awaits (`runCommand` in `internal/web/ui/src/app/commands.ts`) is a popup the browser blocks. Give it `target="_blank"` and `rel="noopener noreferrer"`. **Convention** — a button that does nothing when tapped, with no error.
- **Leave the classic app (`internal/web/static/`) as it is until cutover, changing it only to keep the switch working.** Every paired device runs it until its owner switches, and it is the way back; a feature or fix written there is a second app to keep in step. **Convention** — a fix that lands in one app only.
- **Give a `truncate` element `block` (or make it a flex or grid child), and clip a path or a name only in an element that is not `inline`.** Tailwind's `truncate` sets `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`, and none of it applies to an inline `<span>`, so a long directory or `from <old_path>` in the changes panel (`internal/web/ui/src/panels/changes/Changes.tsx`) runs on past its column into the counts beside it. **Convention** — a row that overflows only on a phone with a long path, passing every test and the webshot fixtures, whose paths are short.
- **Scroll a panel only through `useScrollPane()` (`internal/web/ui/src/app/scroll.tsx`), never through `window`; a desktop pane keeps its pinned head outside the scroller (`elementPane(scroller, null)`) and draws its Body only once the scroller has mounted.** The pane is the window on the phone (`windowPane`) and the middle's or the inspector's own element on desktop, where the page does not scroll: a panel that reads `window.scrollY` stops following the conversation's newest turn, never reaches a job log's end and lands a flow document's jump nowhere, and a Body drawn before its scroller exists keeps the window's pane. **Enforced** for the pane by `internal/web/ui/src/app/scroll.test.tsx`, for the three panels that scroll by `turns.test.tsx`, `job.test.tsx` and `doc.test.tsx` under `internal/web/ui/src/panels/`, and for each desktop pane by the cases `gives the screen the scroller's pane and never reads the window's scroll` (`DesktopShell.test.tsx`) and `gives the panel the inspector's pane and never reads the window's scroll` (`Inspector.test.tsx`, both in `internal/web/ui/src/desktop/`); another panel reading the window is **Convention** — a view stuck on desktop.
- **Read a session in a panel's Body only from its props (`PanelProps.sessionId`, `params`), never from the route (`useRoute`, `panelProps(route)`); a Head or a Strip may read the route.** The inspector draws a tab's Body through `PanelHost` with `{ sessionId, params: { id }, search: {} }` beside a middle that shows another route, so a Body that reads the route draws the middle's session in the inspector; only the middle draws a Head or a Strip, and `NoSession` takes `sessionId` as a prop for this. **Enforced** for `NoSession` by the case `NoSession reads no route` in `internal/web/ui/src/session/session.test.tsx` and for the props the inspector hands a Body by the case `draws the chosen panel's Body with the session's props` in `internal/web/ui/src/desktop/Inspector.test.tsx`; another Body reading the route is **Convention** — an inspector tab that shows the wrong session with no error.
- **Draw the desktop's top bar, sidebar and inspector from `internal/web/ui/src/desktop/` as chrome, never as a panel (`definePanel`), and denser than a panel: no 44px minimum.** A panel gets a URL, a tab and a Head, so chrome registered as one would answer a route and sit among a session's tabs; the 44px targets and 16px form text stay in the panels, which the phone also draws. Chrome reuses the shared pieces (`LinkPill`, `HostLabel` and `GroupCounts` in `internal/web/ui/src/app/status.tsx`, `FleetLinks` in `internal/web/ui/src/panels/fleet/FleetHead.tsx`, `WorkspaceFilter`) instead of a copy, so the phone's footer and the top bar cannot drift. **Enforced** for the density by `internal/web/ui/src/desktop/TopBar.test.tsx`, `internal/web/ui/src/desktop/Sidebar.test.tsx` and `internal/web/ui/src/desktop/Inspector.test.tsx`; that chrome is not a panel is **Convention** — a sidebar that is reachable at a URL and listed among a session's tabs.
- **Keep `DesktopShell` (`internal/web/ui/src/desktop/DesktopShell.tsx`) a `React.lazy` module of its own that `AppShell` draws only at `desk2` and wider, and mount the one `ConfirmSheet` and the one `Toaster` in `AppShell` above both frames, never inside `PhoneShell` or `DesktopShell`.** A static import puts the desktop code in the entry script and slows every phone launch; a sheet or toaster inside a frame unmounts when the window crosses 1024px, so an open confirmation's command waits for an answer nobody can give and a toast is lost. **Enforced** for the chunk by `TestDist_LazyViewsAreChunksOfTheirOwn` and `TestCheckLazyViews_RefusesAMissingChunkAndAPreloadedOne` (`internal/web/static_budget_test.go`, `DesktopShell` in `checkLazyViews`' list), and for the sheet and toaster by the cases `keeps an open confirmation across a swap, redrawn as a dialog, and it still answers` and `keeps a toast showing across a swap, at the top on the phone and the bottom right on desktop` in `internal/web/ui/src/app/shell.test.tsx`.
- **Bind a document `keydown` listener only through `usePaletteKey` (`internal/web/ui/src/desktop/paletteState.ts`), called by `DesktopShell`: ⌘K and Ctrl+K are the app's only key listener, and they toggle the palette from anywhere, a text field included, and do nothing while `confirmOpen()` (`internal/web/ui/src/app/ConfirmSheet.tsx`) is true.** A listener bound elsewhere loads in the phone's entry and runs where no palette is drawn, a second one steals keys from a text field, and a chord pressed over a confirmation would stack a palette on it. **Enforced** for the chord by the cases `toggles the palette on the chord from a text field` and `does nothing while a confirmation is open, and still prevents the browser's default`, and for the one listener by `adds one keydown listener on the document and removes the same one on unmount`, all in `internal/web/ui/src/desktop/paletteState.test.ts`; another listener elsewhere is **Convention** — a key that acts on the phone or inside a field.
- **Import xterm.js and its addons (`@xterm/xterm`, `@xterm/addon-webgl`, `@xterm/addon-fit`) only from the script of `terminal.html` (`internal/web/ui/src/terminal/main.ts`); that document is the one place a runtime `<style>` is allowed.** xterm.js appends `<style>` elements at run time that the app's `default-src 'self'` policy drops, so it runs in a document of its own that the web layer serves under `terminalCSP`, and an import from the app's entry would put it in every phone launch, running under the policy that blanks it. **Enforced** by `TestDist_XtermLoadsOnlyInTheTerminalPage`, which fails on xterm.js in a file the app's first load fetches or in any script the terminal page does not load; a runtime style elsewhere is **Convention** — a view that is unstyled only under the app's policy.
