# internal/web/ui

The web layer's new phone app: its source is here (React, TypeScript, Vite, Tailwind and shadcn on Base UI), `pnpm run build` writes it into `internal/web/dist/`, which the daemon embeds and serves to a device that chose it, and the classic app in `internal/web/static/` stays beside it until cutover.

## Rules when modifying this app

- **Never edit `internal/web/dist/` or `internal/web/ui/src/api/gen.ts` by hand; rebuild with `pnpm run build` and regenerate with `go generate ./internal/web`, and commit the result with the source change.** The bundle is what the daemon serves and `gen.ts` is the Go contract's TypeScript, so a hand edit is overwritten by the next build, and a source change committed without its bundle ships the old app. **Enforced** by `pnpm run dist:check` (CI's `.github/workflows/web.yml`, the step "Bundle is fresh") for the bundle and by `TestContract_GeneratedFilesAreFresh` for `gen.ts`.
- **Add a view only as a panel and an action only as a command.** A panel (`definePanel`, `internal/web/ui/src/app/panels.ts`) is imported from `internal/web/ui/src/panels/index.ts` and given its URL in `routeOf` and `hrefFor` (`internal/web/ui/src/app/routes.tsx`); a command (`defineCommand`, `internal/web/ui/src/app/commands.ts`) is drawn by `CommandButton`. The registries give every view its tab and error boundary and every action its confirmation, toast and stale gate; a view or button wired by hand skips them and acts on a stale fleet. **Convention** — a button that acts on a snapshot the daemon has since changed.
- **A command's `when` reads only the session's status and group, its `claude` flag, the route and the link state, and only an `offline` command runs while the snapshot is stale.** The model decides what is allowed and a wrong guess is its 409, shown as a toast; `group` is read because only it tells a Recoverable or unstarted Ready session from a started Ready, as the classic actions do; a copied precondition drifts, then offers what the daemon refuses or hides what it allows. Only `app.backToClassic` and `device.pair` are `offline`, because the switch must work with the daemon down and pairing runs before any snapshot exists. **Enforced** for the stale gate by `internal/web/ui/src/app/commands.test.ts`; what `when` reads is **Convention** — a button that does nothing, or an action missing.
- **Write no runtime `<style>`, no `style` attribute as markup and no HTML built from a string, and draw Claude's text from its tree (`blocks`) as elements and text nodes.** The Content-Security-Policy is `default-src 'self'`: it drops an injected style or inline attribute without a word, and a string put into the page renders whatever markup Claude's text holds. React's `style` prop is not a `style` attribute, since it sets the property through the CSSOM, which the policy allows, so a bar's computed width or height (`Bars` in `internal/web/ui/src/panels/flow/parts.tsx` and the cost box's and the flows list's bars, which take exact percentages) goes through the prop, never through a `style=` string in markup and never through one class per step. Import a component's CSS statically and keep `main.tsx`'s Base UI `CSPProvider` with `disableStyleElements`. **Enforced** for the shell by `TestStatic_NextIndexHasNoInlineScriptOrStyle` and for a violation at run time by webshot under the real policy (CI's `.github/workflows/web.yml`, the step "Render every route"); the rest is **Convention** — a view that is blank or unstyled only on the phone.
- **Take every colour and font from the tokens in `internal/web/ui/src/styles/app.css`, and keep form text at 16px, touch targets at 44px (written in px: `min-h-[44px]`) and the safe-area insets.** The skin is dark only, its tokens arranged so a light set drops in as a second block of the same names, and iOS zooms into a form control under 16px; `html` sets 13px, so a rem class like `min-h-11` is 35.75px, short of 44. **Enforced** for the tokens by `TestDist_TheSkinDefinesEveryToken`, which reads the built CSS; using a token rather than a literal, and the phone sizes, are **Convention** — a skin that cannot be re-themed, a page that zooms on focus.
- **Keep the first load within `firstLoadBudget`: load a screen the first view does not need (the flow views, job, mockup, new session, settings) through a dynamic `import()`, so it builds into a chunk of its own.** `internal/web/static_budget_test.go` sums the gzipped entry script and every `modulepreload` that `internal/web/dist/index.html` names, and a heavier bundle slows every launch on a phone. **Enforced** by `TestDist_FirstLoadIsWithinBudget`.
- **Make a view the first load does not need a panel whose `Body` is `React.lazy` over a module of its own, keep its `Head` in the entry, and let `PanelHost` draw it under its `Suspense`.** A view imported statically lands in the entry script and slows every launch on a phone, and a lazy `Head` leaves the header empty until its chunk loads; the job view (`internal/web/ui/src/panels/job/JobBody.tsx`) is the pattern, and the conversation, info, changes and subagent views and pairing stay in the entry because a push opens the conversation and an unpaired launch opens pairing. **Enforced** for the chunks `checkLazyViews` lists (`JobBody`, `MockupBody`, `FlowBody`, `FlowStoryBody`, `FlowDocBody`, `FlowsBody`, `NewSessionBody` and `SettingsBody`), to which a new lazy view adds its stem, by `TestDist_LazyViewsAreChunksOfTheirOwn` (`internal/web/static_budget_test.go`); another view imported statically is held only by `TestDist_FirstLoadIsWithinBudget` — a heavier launch until the budget fails.
- **Take the type of every JSON shape the daemon sends from `gen.ts`, and never write one by hand.** A hand-written copy drifts from the Go struct and the app then reads a field that is gone with no error; the generated type fails the typecheck instead. **Enforced** for the fixtures by `internal/web/ui/src/fixtures.test.ts`, which holds each `tools/webshot/fixture` answer to its route's generated type; a hand-written copy is **Convention** — a screen that renders empty after a Go change.
- **Read the daemon from a view only through `internal/web/ui/src/api/reads.ts`, never with a `fetch` or an `api.<client>` call that sends a request from a component of its own; `api.mockupURL`, which only builds a URL, is not one.** The module holds the classic app's refresh rules and its caches in the query cache: one request in flight with a load asked meanwhile run once it lands, no retry (the next poll is the next attempt), the pages and scroll of the last 8 conversations and the logs of the last 5 jobs kept, and an unpair clears them through `queryClient.clear()`; a read a component writes itself refetches on every mount, polls without those rules and keeps a stranger's pages after an unpair. **Enforced** for the rules by `internal/web/ui/src/api/reads.test.ts`; that a component reads only through the module is **Convention** — a screen that polls twice or shows another account's turns.
- **Draw Open in Claude, and every other link that acts on nothing in loom, as a plain `<a>`, never as a command.** Such a link (`claude ↗` in `internal/web/ui/src/session/SessionHead.tsx`, the needs-you box's Open in Claude) changes no state, so it needs no confirmation, in-flight key or stale gate, and a window opened after a command's awaits (`runCommand` in `internal/web/ui/src/app/commands.ts`) is a popup the browser blocks. Give it `target="_blank"` and `rel="noopener noreferrer"`. **Convention** — a button that does nothing when tapped, with no error.
- **Leave the classic app (`internal/web/static/`) as it is until cutover, changing it only to keep the switch working.** Every paired device runs it until its owner switches, and it is the way back; a feature or fix written there is a second app to keep in step. **Convention** — a fix that lands in one app only.
- **Give a `truncate` element `block` (or make it a flex or grid child), and clip a path or a name only in an element that is not `inline`.** Tailwind's `truncate` sets `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`, and none of it applies to an inline `<span>`, so a long directory or `from <old_path>` in the changes panel (`internal/web/ui/src/panels/changes/Changes.tsx`) runs on past its column into the counts beside it. **Convention** — a row that overflows only on a phone with a long path, passing every test and the webshot fixtures, whose paths are short.
