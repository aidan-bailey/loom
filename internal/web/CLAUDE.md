# internal/web

The daemon's web layer, started by `loom serve`: a client of the daemon's own `rpc.Server` plus `core.WebHost`, serving the loom PWA on a loopback port that a Cloudflare tunnel reaches (pairing, a JSON API, a live stream, Web Push). It holds no session state: the model owns every session and every device record.

## Rules when modifying this package

- **Decode a request body only with `readJSON`, and answer only with `writeJSON` and `writeError`.** `readJSON` refuses an empty body, a field the route doesn't take, a second value and a body past the cap, so a misspelt field is a 400 rather than a silently ignored value; the writers encode before the header, so a value that won't encode is a 500 with a fixed body, never a 200 with half of one. **Enforced** by `TestReadJSON` and `TestWriteJSON_AValueThatWillNotEncodeIsA500`.
- **Authenticate a request only through `authed`, which decodes the cookie's unpadded base64url token, refuses one that is not exactly 32 bytes, and asks the host by the SHA-256 of those bytes.** The model stores the hash of the 32 bytes, so the layer never holds, logs or compares a token, and hashing the cookie's text instead matches no device; a cookie that does not decode to 32 bytes never reaches the host. A cookie that names no device is a 401 before the route runs; a route registered without `authed` is open to the internet. **Enforced** for the check by `TestTokenHash`, `TestAuthed_AGoodCookieNamesItsDevice`, `TestAuthed_TextThatDoesNotDecodeIsRefusedWithoutAskingTheHost`, `TestAuthed_TextOfTheWrongLengthIsRefusedWithoutAskingTheHost`, `TestAuthed_AWellFormedTokenNoDeviceHoldsIsRefused` and `TestAuthed_NoDeviceCookieIsRefusedWithoutAskingTheHost`; that every route uses `authed` is **Convention** — an API route anyone can call.
- **Set and clear the device cookie only through `setDeviceCookie` and `clearDeviceCookie`.** They give the `__Host-loom` cookie its attributes (Secure, HttpOnly, SameSite=Strict, Path=/, the lifetime `cookieMaxAge`); a browser drops a `__Host-` cookie without Secure or Path=/, and without HttpOnly or SameSite=Strict a script or a cross-site request could carry it. **Enforced** by `TestDeviceCookie`.
- **Map the host's pairing refusals by sentinel with `errors.Is` (a wrong code 400, too many wrong codes 429, a name taken or 16 devices 409, the web off 503), answer the sentinel's own text, and give any other error a fixed 500.** The model's errors can carry paths and device names, and the app tells a wrong code from a locked one by status; a wrong code answered 401 reads as "not paired" and clears the app's snapshot. **Enforced** by `TestPair_AnswersWhatTheHostSays` and `TestPair_TakesPostOnly`.
- **Wrap every route in `guard`, let a layer with no origin rule refuse everything, and keep `guard` handing the handler the `ResponseWriter` it was given (or a wrapper with `Unwrap() http.ResponseWriter`).** `guard` answers 421 unless the Host header is the origin's host (DNS rebinding), 403 for any method but GET and HEAD without the origin's own `Origin` header (a cross-site post), puts the security headers on every answer and caps bodies at `maxBody`; a listener bound without a rule would answer any Host, and a wrapper without `Unwrap` makes `http.NewResponseController(w).Flush()` fail, so the live stream would buffer until it closes. **Enforced** by `TestGuard_TheHostMustBeTheOrigins`, `TestGuard_AnUnsafeMethodMustCarryTheOrigin`, `TestGuard_EveryAnswerCarriesTheSecurityHeaders`, `TestGuard_NoRuleAnswersNothing`, `TestGuard_TheBodyIsCapped`, `TestGuard_AHandlerBehindItCanFlushToTheClient` and `TestParseOrigin`.
- **Join the daemon's server only as `rpc.RoleWeb`.** The server keeps a notice for the next TUI only while no other connection exists, and the always-connected web client would swallow every notice raised while no TUI is open. **Enforced** by `TestStart_ANoticeRaisedWithOnlyTheLayerConnectedWaitsForTheNextTUI`.
- **Change the listener only from the drain, only on a loopback IP literal, and leave the web off when a bind fails.** A failed or refused address reported as serving, or a fallback to another address, exposes a port nobody chose. **Enforced** by `TestApplyWeb_ListensOnceTheModelEnablesTheWeb`, `TestApplyWeb_ChangingTheListenAddressMovesTheListener`, `TestApplyWeb_ChangingOnlyTheOriginChangesTheGuard`, `TestApplyWeb_DisablingStopsServing`, `TestApplyWeb_ATakenPortLeavesTheWebOffAndSaysWhy` and `TestBind_ListensOnLoopbackOnly`.
- **Rebind exactly when `WebView.Rev` differs from the last one the layer acted on: never by comparing `listen` and `origin`, and never on a `WebServing` report.** Every `ConfigureWeb` bumps `Rev` and nothing else does, so a disable and an enable that one `Sync` coalesces into a single `ModelChanged` (the settings already bound) still rebind, a retry with the very values that failed still binds, and the layer's own report does not end every open stream by rebinding. Compared by key, a coalesced pair or a retry leaves no listener while the model's `listen` is set, and nothing says why. **Enforced** by `TestApplyWeb_TwoConfigurationsCoalescedIntoOneSyncStillRebind`, `TestApplyWeb_TheSameSettingsAgainRetryAFailedBind` and `TestApplyWeb_AWebServingReportNeverBinds`.
- **Tell the host (`WebServing`) only what the layer did, and clear only an error the layer set.** A `web.json` the model left alone keeps its reason in `WebView.Error` with `listen` empty; reporting "off" over it would wipe the only explanation of why the web is dead. **Enforced** by `TestApplyWeb_OnlyWhatTheLayerDidIsReportedOff`, which calls `applyWeb` with a recording host; `TestApplyWeb_AWebJSONTheModelLeftAloneKeepsItsReason` pins the same through a real model.
- **Defer `l.recoverPanic(where)` first in every goroutine the layer starts, and stop the layer only through `fail` or `Close`, never by waiting for the stop `fail` starts.** A panic stops the layer, reports it through `WebServing` (a notice for the next TUI) and leaves the daemon running; `fail` returns at once and runs the one stop `Close` also runs, on a goroutine of its own, so a part may call it from the goroutine the stop waits for. **Enforced** by `TestDrain_APanickingSinkStopsTheLayerNotTheDaemon`, `TestRecoverPanic_StopsTheLayerAndNamesWhere`, `TestFail_ReturnsAtOnceFromTheDrainItself` and `TestFail_RacingAClose_StopsOnceAndHangsNowhere`; the goroutines later parts start are **Convention** — a panic that takes the daemon down.
- **Run sinks only on the drain, and never block or do network I/O in one.** A sink that blocks stalls the drain, so the client's queues grow and every part stops following the model. **Enforced** by `TestDrain_HandsEveryBatchToEverySinkInTurn`; a sink that blocks is **Convention** — a layer that silently stops following the daemon.
- **Set the cookie to exactly the token text the host returns, and hash the 32 bytes that text decodes to, as the model does.** Hashing the cookie's text on one side and the bytes on the other makes every paired phone a stranger, every route answering 401 with nothing logged. **Enforced** by `TestPair_ACodeFromTheModelPairsAPhoneOnce` and `TestAuthed_RevokingADeviceRefusesOnlyItsCookie`.
- **Start the layer after the mod server and close it first when the daemon stops, before the server's bye (`daemon.Serve`).** The streams hear their own bye and the listener closes before any client is told the daemon is stopping, so a phone shows "loom is restarting" rather than a dropped connection, and no request of a phone reaches a loop that is quiescing. A layer that can't start costs only the web. **Enforced** by `TestServe_ServesTheWebLayerOnceWebJSONEnablesIt`, `TestServe_AStopClosesTheWebListenerBeforeAnyClientHearsTheBye` and `TestServe_TheWebLayerComesBackWithTheNextDaemon` (`internal/daemon/serve_test.go`); that a failed start leaves the daemon running is **Convention** — a daemon that exits because the web could not start.
- **Add a route, a stream event or a push kind by the checklist in [`docs/claude/web-layer.md`](../../docs/claude/web-layer.md).** A piece missed (the app's call, the snapshot's field, the README's table) fails nothing on the server and shows only on the phone. **Convention** — a route the app never calls, an event it ignores, a push the worker does not show.
- **Answer a refused action 409 with the model's own text and a stopping daemon 503, and never copy `admit`'s or `precondition`'s checks here.** A copy drifts, and the phone then offers what the TUI would refuse or withholds what it allows; the app's buttons only follow the session's `status`. **Enforced** for the statuses by `TestAPI_ARefusalIs409WithTheModelsText` and `TestAPI_AStoppingDaemonIs503`; not copying `admit` is **Convention** — a button that does nothing, or an action missing.
- **Put a request's notices in its response and keep them among the recent notices the snapshot carries, send a later one to the requesting device's stream, and have the app always show Kill's and Resume's stash notices.** They name a SHA that may be the only record of the work, so a notice dropped loses it silently; the daemon also hands a notice tied to the web client's request to its other clients, or keeps it for the next TUI, since the phone may never see it. **Enforced** for the response and the kept notices by `TestAPI_AResponsesNoticesAreKeptForTheNextSnapshotAndNotSentLive` and `TestAPI_AnOpThatWorksAnswers200WithItsNotices`; the app's showing the stash notices is **Convention** — work that cannot be found again.
- **Start every stream with a `snapshot`, replay nothing, ping every `pingEvery` (20 s), give the stream no write timeout over its whole life (each event's write is bounded at `streamWriteTimeout`, 30 s), and hold at most `maxStreamsPerDevice` per device and `maxStreams` in all.** Cloudflare closes a stream idle for 125 s; a replay shows the phone a state that no longer holds; no cap lets one phone or one bug take every stream. **Enforced** by `TestStream_StartsWithASnapshot`, `TestStream_PingsKeepItOpen`, `TestStream_EachFrameIsWrittenUnderADeadlineThatIsClearedAfter`, `TestStream_AFifthStreamEndsTheDevicesOldest` and `TestStream_ThirtyTwoStreamsAreTheMost`.
- **Treat the first projection after the layer starts as a baseline that pushes nothing, push each transition once, and never push for a workspace terminal.** A daemon restart would otherwise send one push per waiting session, and a terminal's status is not a user's turn. **Enforced** by `TestPushWatch_TheFirstProjectionIsABaseline`, `TestPushWatch_WaitingFiresOnEnteringPrompting` and `TestPushWatch_WorkspaceTerminalsNeverPushOrCount`.
- **Post a push only to a subscription `core.ValidatePushSubscription` passed, from the sender's own goroutine, with a 10 s timeout, at most 30 pushes a minute per device, a queue of at most 100, and none while the web is off (an empty `listen`).** The daemon connects to whatever host a subscription names, so an unvalidated one makes it a proxy into the user's network; a send on the loop or in a sink stalls the model; and a user who turned the web off expects the phone to go quiet. **Enforced** by `TestWebHost_ValidatePushSubscription_Endpoints`, `TestPusher_AtMostThirtyPushesAMinutePerDevice`, `TestPusher_QueueHoldsAtMostOneHundredPushes`, `TestPusher_SendsNothingWhileTheWebIsOff` and `TestPusher_NeverFollowsARedirect`; the sender goroutine and the 10 s timeout are **Convention** — a send that stalls the model or hangs on a dead service.
- **Build the payload encryption from the standard library only, and change `internal/web/webpush` only with RFC 8291's own example vector still passing.** A push service answers 201 to ciphertext it cannot read, so a wrong one shows only as a phone that stays quiet. **Enforced** for the encryption by `TestEncryptWith_RFC8291Example`; **Convention** for the standard-library-only part — a dependency that drifts from the RFC without a failing test.
- **Serve the app's shell public and free of data, with no inline script and no `style` attribute, and let the service worker cache the shell only, never `/api/`.** The Content-Security-Policy is `default-src 'self'`, which drops an inline handler without a word, and a cached response shows a stale fleet as live. **Enforced** for the shell and the modules by `TestStatic_IndexHasNoInlineScriptOrStyle` and `TestStatic_ModulesSetNoStyleAttribute`; **Convention** for the worker's cache — an old fleet shown as current.
- **Write the app's modules as `.mjs`, and keep the Preact file at `internal/web/static/lib/preact-htm.mjs`, never under a `vendor/` dir, with its SHA-256 pin changed in the same commit.** `node --check` misses syntax errors in a `.js` module, and Go's module zips drop files below a nested `vendor/`, so a `go install` build would embed no such file and the app would not load. **Enforced** for the pin by `TestPreactHTM_IsThePinnedFile`; **Convention** for the extension and the location — a broken module that passes every Go test, or an app missing from an installed build.
- **Change the JSON the app reads only by adding fields, and never rename or retype one in `/api/v1`.** An installed app may run against a newer daemon until its service worker updates; an older app reading a renamed field shows nothing and fails no request. **Convention** — a screen that renders empty after a daemon upgrade.
- **Log every action under `subsystem=web` with its device, action, session and result, and never log a token, a cookie, a pairing code or a push subscription.** A log line is read by other users and pasted into bug reports, and these are credentials. **Enforced** for the log fields by `TestAPI_EveryAnswerIsLoggedWithItsStatus`; never logging a credential is **Convention** — a credential in a file that outlives the pairing.
