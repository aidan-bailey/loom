# session/claudemod

The loom mod for Claude Code: a function-hook plugin (`mod/`: the manifest, `hooks/hooks.json`, the TypeScript module `hooks/register.ts`) embedded in the binary, which `session` writes into each Claude launch's hooks folder (`WriteTo`) and passes with `--plugin-dir`. The module long-polls the daemon's mod socket (served by `internal/modserver`), submits each message with `$.prompt.submit` (or runs a command message with `$.command.run`, reporting `complete` with its output) and reports it `queued`. Its hello lists Claude's commands, which the daemon judges a command by. Claude runs every message queued during one turn together, as one turn, and resolves a submit as the turn carrying it starts, so the module claims a resolved message for the running main-loop turn, or the next one, reports it `started` with that turn and `complete` when the turn ends, and `failed` when Claude drops it; it never matches a turn's text. Design: [`../../docs/superpowers/specs/2026-10-14-loom-claude-mod-design.md`](../../docs/superpowers/specs/2026-10-14-loom-claude-mod-design.md), as amended by its plan, [`../../docs/superpowers/plans/2026-10-14-loom-claude-mod.md`](../../docs/superpowers/plans/2026-10-14-loom-claude-mod.md), whose amendments win where they differ.

## Rules when modifying this package

- **Keep the module a carrier: compose text, decide policy and judge liveness in Go (the model, in `core`), never in TypeScript.** The module ships on Claude's early-access API and nothing in CI runs it; the Go side is where the tests are. **Convention** — logic only an opt-in real-Claude run exercises.
- **Keep the module's reach to `$.env`, `$.http`, `$.prompt`, `$.command`, `$.session`, `$.clock` and `$.ui.log`, and run a command only as the daemon hands it one (`ModMessage.Command`).** It runs inside every Claude loom launches; `$.process` or `$.fs` there would make every session a host for whatever reaches the socket, and a command run on the module's own judgement would bypass the daemon's rules, which refuse every built-in that may open a menu or end the session (`commandRefusal`). **Convention**, checked by the opt-in `TestRealClaude_ValidatesTheMod` (`LOOM_TEST_REAL_CLAUDE=1`; CI never runs it), which pins the validator's call list — a module reaching further, unnoticed until someone runs it.
- **Change `Version`, the manifest's major version, `MOD_VERSION` and the `/v<n>` path together, and only for a change an older daemon or module would misread.** A mod from an older build talks to a newer daemon after an upgrade. **Enforced** for the three agreeing by `TestModule_SpeaksThisProtocol` and `TestWriteTo_WritesTheWholeMod`; the need for a bump is **Convention** — a mod and daemon misreading each other silently.
- **Name the module instance in its hello and every poll (`POLLER`, minted once as the module loads), send its load time in its hello (`LOADED`), and stop the pump for good on a 409 from either, never starting it again in that instance.** The daemon lets only the instance loaded last poll, whichever hello lands last, so a pump that outlived a reload stops instead of waking the new one's held poll with each of its own, and being woken by it, in a tight loop; and after a daemon restart the stale one, whose turn hooks are gone, can't take the launch back. **Convention** for the module, which only the opt-in real-Claude run loads; the daemon's side is **Enforced** by `TestMod_ThePollerOfTheLatestHelloWins`, `TestMod_AfterARestartTheModLoadedLastWins`, `TestInbox_ASupersededPollerIs409` and `TestHello_ASupersededModIs409`.
- **Embed with `all:mod`.** A plain pattern skips `.claude-plugin`, and Claude then loads no plugin at all. **Enforced** by `TestWriteTo_WritesTheWholeMod`.
- **Write the mod per launch, into the hooks folder, never into a folder sessions share.** Claude writes `tsconfig.json` and `.claude-plugin/types/` into every `--plugin-dir` folder it loads, and saving a module file in a watched folder hot-reloads the module in every session watching it. **Convention** — sessions rewriting and reloading each other's mod.
- **Run the opt-in real-Claude tests (`LOOM_TEST_REAL_CLAUDE=1`, `-run RealClaude`, here and in `internal/modserver`) after changing the module.** CI has no `claude`, so nothing else type-checks the module or drives it against Claude. **Convention** — a module Claude refuses, and every session silently without it.
