# core

The session model: `core.Model` serves every registered workspace to every client, runs on a `core.Loop` in the daemon, and changes only by request. Full reference in [`README.md`](README.md).

## Rules when modifying this package

### Tasks

- **Adding or changing a `Core` method?** Its line comment in `core/iface.go` (`rpc:local`, `rpc:cast`, `rpc:client`, or none for a request) decides how a client serves it, the wire in `core/rpc` is generated from that file, and a local query needs a state-view method that answers as the model does. A query whose view method disagrees answers one way in process and another through the daemon, with nothing failing at the call site. **Enforced** by `TestMethods_CoverCore`, `TestGenerated_IsFresh`, `TestLoopForwardsEachMethodToItsNamesake`, `TestStateViews_AnswerAsTheModel` and `TestReplica_AnswersAsTheModel` once each has its case. Guide: [`../docs/claude/adding-a-core-method.md`](../docs/claude/adding-a-core-method.md)
- **Adding an event?** List it in `EventTypes()`, keep it plain data, give a state event a coalescing key in `core/rpc/server.go`, route an event naming a request through `forConn`, and give the TUI an applier. A missing applier passes the app suite whenever its fixture reseeds every view. **Enforced** by `TestAllEventsListsEveryEvent`, `TestCoreIsValueTyped`, `TestCoalesceKeys_MatchTheReplicasStateEvents` and `TestForConn_CoversEveryEventNamingARequest`; the applier is not. Guide: [`../docs/claude/adding-a-core-event.md`](../docs/claude/adding-a-core-event.md)
- **Adding throttled background work?** Dispatch it through `dispatchGated` with a `gateKind` and a `gateIntervals` entry, return `nil` from the builder when there is nothing to do, and let `deliverGated` disarm before your handler runs. A gate armed with no job, or a result that skips the disarm, latches the job off until the daemon restarts, silently. **Enforced** for today's jobs by `TestProductionGatedJobsYieldOneResult` and `TestGatedDeliveryDisarmsFirst` (`core/gate_test.go`); a new job needs its own case. Guide: [`../docs/claude/adding-a-gated-job.md`](../docs/claude/adding-a-gated-job.md)

### Requests, jobs and completions

- **Every lifecycle action is a request that runs `admit` first.** `admit` refuses an ID no served workspace holds (`ErrNoSession`) and an instance failing `precondition`, which mirrors the keys' gates in `app/intents.go` so the model refuses exactly what no key can do (a script or another client included); a refusal matches `core.ErrRefused`, and with `ReqID` 0 is only logged (`request.refused`). A new request without its precondition, or a new key gate without the matching one here, lets one client do what another's keys forbid. **Enforced** for today's requests by `TestRequests_RefuseWhatTheTUIRefuses` and `TestRequests_RefusalsMatchErrRefused` (`core/requests_test.go`); a new request needs its case.
- **A `Job` reads no model state.** It runs on its own goroutine while the loop keeps applying results, so capture its inputs on the model's goroutine when building it (`saveSnapshot`, `recoverInst`, the owner's storage in `killInst`/`pauseInst`) and return a result for `Deliver`. **Convention** — a torn or stale read that only `CC=clang CGO_ENABLED=1 go test -race` catches, and only when a test overlaps it.
- **Nothing on the loop's goroutine waits on a client or calls the loop.** A loop call made from inside a loop call deadlocks, and the TUI's requests have no timeout, so a wedged loop freezes every TUI at its first action. **Convention** — a frozen daemon and frozen TUIs; diagnosis in [`../docs/claude/debugging-freezes.md`](../docs/claude/debugging-freezes.md).
- **Completions act on the instance they carry and the owner stamped at dispatch.** A failed start removes and kills its own instance (`killUnstarted`), a `KillResult` removes its instance from every workspace (`removeEverywhere`), an `OpFailed` reverts its own, and `StartResult.Owner`/`ResumeResult.Owner`/`RecoverResult.Owner` resolve through `owningWorkspace`; never reach for a selected instance or a list position. The user and other clients act while a job runs. **Convention** — a completion that lands on whatever took the instance's place.
- **Keep a request's cause ambient.** Emit through `emit` and spawn a request's follow-on jobs through `spawn`, so `Started`, `Recovered` and `Notice` carry `Req` (`Model.cause`) and reach the client that asked; the model's own jobs (tick probe, gated jobs, dead checks) go through `spawnBackground`. A follow-on spawned in the background loses its Reply's routing (no inline attach for the requester), and a background job spawned as a request's makes `Loop.Quiesce` wait on it at stop. **Enforced** for today's chains by the `TestCause_…` tests (`core/cause_test.go`).
- **Assign each `InstanceID` and `WorkspaceID` once and never reuse one; 0 is never assigned.** A request by a stale ID must be refused, not land on an instance that took a removed one's place, and the TUI's draft row is ID 0. **Enforced** by `TestIDs_StableNeverReusedAndForgotten` (`core/view_test.go`).

### Boundaries

- **Keep `Core` value-typed.** Every parameter, result and `Event` is plain data a client in another process could be sent: no func, chan, `sync` type, interface but `error`/`Event`, or model object. **Enforced** by `TestCoreIsValueTyped` (`core/value_boundary_test.go`).
- **Import nothing of the TUI.** No `app`, `ui/...`, `script`, `keys` or `charm.land` package, directly or through another loom package. **Enforced** by `TestCoreImportsNoUI` (`core/boundary_test.go`).
- **Keep `…ForTest` seams in `core/seams.go` and out of production code.** **Enforced** by `TestNoProductionCallsOfTestSeams` (`internal/testenv/seams_enforce_test.go`), which also catches a seam taken as a value.
- **Give a state view's `Clone` a deep copy of every slice and map, and every other field unchanged.** Replicas answer from clones, so a field `Clone` drops is lost to every client (a dropped `LastUsed` once made every restore focus the first tab). **Enforced** for the fields their fixtures set by `TestModelView_CloneKeepsEveryField` and `TestGitHubView_CloneKeepsEveryField`; set a new field in the fixture too.
- **Hand out copies from every query.** A caller editing a returned map or slice must not reach the model's. **Enforced** for today's queries by `core/copies_test.go`.

### Claude status and the roster

- **Write a reported status only through `adoptClaudeStatus`.** It applies the status and records `Instance.WaitReason` together; `deliverHealth` and `applyClaudeStatus` both call it, and the TUI's ladder writes no status. A second writer leaves a wait reason behind a status it no longer explains, or lets a scraped guess cover Claude's own answer. **Convention** — a stale "awaiting input" label.
- **Keep the roster fail-closed: no opinion on any doubt, and a failed query clears it.** A non-Claude agent, no entry for the worktree, an ambiguous cwd, a background-only cwd or an unknown status string returns no opinion from `rosterStatusFor`; a failed query sets `roster` to nil and voids every roster-sourced observation (a hook-sourced one stands). A stale roster keeps driving transitions long after it stopped being true. **Enforced** by `TestRosterResultErrorClearsEntries` and `TestFailedRosterKeepsHookStatus` (`core/claude_status_test.go`).

### GitHub poller

- **Leave `ghAvailable.ok` a one-way latch to true, and re-probe an unavailable answer every `ghRecheckInterval`.** gh breaking mid-session shows as per-repo errors, never as an availability flip, while a user who runs `gh auth login` after the daemon started recovers without restarting it. **Enforced** by `TestGHQueryDisabledWhenCLIUnavailable` and `TestGHQueryRechecksAfterBackoff` (`core/github_test.go`).
- **Key base branches by repo (`baseBranchByRepo`), never one string for the batch.** Each workspace has its own `config.json`, and one value would resolve every other repo against the wrong `BaseBranch`. **Enforced** by `TestGHPollJobResolvesPerRepoBaseAndBucketsErrors`.
- **Bound the whole poll with `ghPollBudget`, kept under `ghInterval`.** `github.Query` budgets each `gh` subprocess, so without an overall ceiling one repo with many linked closed issues stalls every other workspace's refresh, and a poll could outlive its own cadence. **Convention** — badges that stop updating for every workspace.
- **Call `UpdateParity` in `probeJob` before the `ShouldRefreshDiff` early return.** That gate skips git for a session with no output, but the base branch moves with no session activity, which is exactly when "N behind main" matters. **Convention** — ahead/behind counts that freeze on idle sessions.
- **Look a repository up only through `ghRepoKey`.** Results are keyed by the checkout's canonical top level, with every other spelling recorded in `ghAliases`; a direct map read misses a session reached through a symlink or a subdirectory. **Enforced** by `TestGHState_AnySpellingOfAPolledRepository`.

### Loading, saving and lifecycle

- **Keep a failed load served, empty and latched, and let `Open` retry it (`retryLoad`).** Its storage refuses writes (`ErrStorageLoadFailed`) so nothing overwrites records loom couldn't read; the boot's sweep leaves its roots out of the owned set, since its titles are unknown, and still sweeps every other workspace. **Enforced** by `TestOpen_RetriesAFailedLoadAndReportsItsError` (`core/boot_test.go`).
- **Save after any change the model makes on its own, through `saveUnprompted`.** The daemon otherwise saves only on requests and at its stop, so a daemon killed first loses the change: an exited agent pausing on the tick (`pauseGone`) would be crash-restarted at the next boot, and a hook scan's conversation ID forgotten. **Enforced** by `TestApplyLiveness_AGoneSessionsPauseIsSaved` and `TestHookScan_ANewConversationIsSaved`; a new unprompted change needs its own.
- **Treat `Recoverable` like Paused in every per-instance loop, and never persist it.** It is re-derived from disk at each load and inert (`EnsureRunning` no-ops); `core.Persistable` filters it out. A loop that drives it touches a worktree no record owns. **Enforced** for persistence by `TestPersistableInstances_ExcludesRecoverable`; loops are **Convention**.
- **Start a workspace terminal at its workspace's first open, and never relaunch one over a held name.** Until `Open` it is dormant (`activeInstances` leaves it out); a dead or Paused one asks `HeldElsewhere` first, leaves another workspace's session running, and on an unanswered check changes nothing and retries from the tick (`maybeSettleTerminals`). **Enforced** by `TestBoot_AnUnopenedWorkspacesTerminalIsDormant`, `TestOpen_ATerminalNameHeldElsewhereIsLeftRunning` and the `TestSettleTerminals_…` tests.
- **Keep launch toggles per config dir (`dirFlags`, set by `syncSessionFlags`).** Every workspace is loaded at once, so one process-wide value would follow whichever loaded last. **Enforced** by `TestBoot_EachWorkspaceSetsItsOwnSessionFlags`.
- **Reload accounts before every user action that reads them, and only stat on the tick.** `ReloadAccounts` runs before Launch Options, Settings and every Accounts-screen request; `maybeReloadAccounts` rereads `accounts.json` only when its size or mtime moved; `accountsChanged` reports a change or load error once, and `noteAccountsState` records the model's own writes so they don't read back as changes. **Enforced** by `TestMaybeReloadAccounts_AnUnchangedFileIsNotReread` and `TestReloadAccounts_AChangeIsReportedOnce` (`core/accounts_test.go`).

### Tests

- **Build models with `NewForTest` and `SetWorkspacesForTest`, a booted one with `bootModel` (`core/boot_test.go`), and call `isolateTmux(t)` in any test that starts real tmux sessions.** On the package's shared server the previous test's cleanup can kill the last session, the server exits, and a `new-session` reaching it fails with "server exited unexpectedly". **Convention** — flaky real-tmux tests.
