# core/rpc

The wire: `core.Core` over newline-delimited JSON between the TUI and the daemon, with a server that publishes to every connection and a client that keeps a replica of the published state. Full reference in [`README.md`](README.md).

## Rules when modifying this package

### Generated code and compatibility

- **Never edit `methods_gen.go`; change `core/iface.go` and run `go generate ./core/rpc`.** The file is generated by `internal/gen`, and a hand edit is overwritten by the next generate or leaves the wire disagreeing with `Core`. **Enforced** by `TestGenerated_IsFresh` and `TestMethods_CoverCore`.
- **Bump `rpc.Protocol` when you remove or rename a method, event or field, or change what a field means or a frame's shape; adding one needs no bump.** A peer answers a method it lacks with `unsupported`, ignores a field it doesn't know and drops an event it doesn't know, but a renamed field decodes as its zero value on the other build, silently. **Convention** — two builds that talk and misread each other; the rule is restated on `Protocol` in `rpc.go`.
- **Rewrite `docs/specs/protocol.md` after any wire change** (`go test ./core/rpc -run TestProtocolReference -update`), never by hand. **Enforced** by `TestProtocolReference`, which byte-compares it and also runs in the Nix build, so a stale reference breaks `nix build` as well as CI.
- **Keep the generator refusing a `ReqID` nested in a parameter.** Dispatch tags only a parameter of type `ReqID` with the connection's number, so a nested one reaches the model as its client numbered it and its Reply goes to another client. **Enforced** by `TestGenerate_RefusesARequestIDTheServerCannotTag` and `TestGenerate_TagsEveryRequestID` (`internal/gen/gen_test.go`).

### Publishing

- **A cast changes no published state.** The server publishes nothing after a cast (pane events cast many times a second), so a change a cast made reaches clients only with some later publish; a method that changes published state is a request. **Convention** — a client that shows the old state until an unrelated event; `core/iface.go` states the rule.
- **Publish a request's events before queueing its reply.** Clients rely on reading a request's effect from their replica the moment it returns (`syncViews` and the TUI's drains). **Enforced** by `TestRequest_ItsEventsArriveBeforeItsReply`, which checks a read right after the request and so can pass by timing alone; the order in the server is **Convention** — a read that sometimes misses the request's effect.
- **Coalesce only state events; never drop or reorder a reply or any other event.** A state event replaces a queued one of the same kind (`coalesceKey`), but a resync can't rebuild a lost `Reply`, and a script waiting on one hangs. **Enforced** by `TestServerConn_CoalescesQueuedState` and, for which events are state, `TestCoalesceKeys_MatchTheReplicasStateEvents`.
- **Never write to a connection from the server's own goroutine.** Each connection's writer goroutine drains its queue (`serverConn`), so a slow or stalled client never blocks the loop or the other clients. **Convention** — one frozen client freezes every TUI.

### Routing

- **Carry the connection in a request ID's high 32 bits, and keep `forConn` covering every event that names a request.** Client IDs collide across clients; `tagReq` tags them, `local` masks them, and a table would leak (a `Create`'s Reply comes at once, its `Started` much later). An event left out of `routed` reaches every client with another client's request ID. **Enforced** by `TestForConn_CoversEveryEventNamingARequest`, `TestTagReq` and `route_test.go`.
- **Keep each connection's selected row its own (`connBackend`), merged for the model through `SetSelection` and dropped when the connection closes.** One client's selection must not starve another's full-diff refresh. **Enforced** by `TestServe_EveryClientsSelectionReachesTheModel`.

### Fatal paths

- **Treat an event that won't encode as fatal, never drop it.** Dropping it could strand a `Reply`'s requester; the server sends `Fatal` with `CodeProtocol` (`server.encode_event_failed`). **Enforced** by `TestEncodeFailure_IsFatal`.
- **Give every new fatal path a check that a normal shutdown can't trip it.** A client closing itself is not a loss (`Close` marks closing first), and a connection closing after a model panic is no crash. **Enforced** for today's paths by `TestClose_IsNotALoss` and `TestServe_AConnectionClosingAfterAModelPanicIsNoCrash`; a new path needs its own.
- **Keep an unknown method an ordinary `unsupported` error, and an unknown event logged and dropped.** A newer client probes an older server this way; making either fatal ends every session of a mixed pair. A known event that fails to decode stays fatal, since it may be a Reply someone waits for. **Enforced** by `TestReply_AnUnknownMethodIsAnOrdinaryError` and `TestEvents_AnUnknownOneIsDroppedAKnownOneThatWillNotDecodeIsFatal`.
- **In `request` and `cast`, copy the fatal and closed state under `c.mu` and panic only after unlocking.** A panic holding the lock blocked the reader and hung `Close`. **Enforced** by `TestPanic_ReachesTheCallerAndEveryLaterCall`, which closes the client after the panics.
- **A daemon's client (`Dial`) never panics: it records the loss in `Err` and wakes the TUI; only an in-process client raises.** A panic in the TUI's process skips restoring the terminal. After the loss, or the server's bye, its requests are refused at once as `core.ErrUnavailable` and its casts dropped. **Enforced** by `TestPanic_ADaemonsClientReportsIt`, `TestConnectionLost_IsFatal`, `TestBye_ARequestAfterItIsRefusedLocally` and `TestInProcess_RaisesTheModelsPanic`.
- **Tell a stop from a crash by the bye, and never send one for a failed model.** A connection lost after a bye is `Err` matching `core.ErrUnavailable` (the TUI waits and starts no daemon); one lost without is a crash (it reconnects and starts one); a fatal frame is a crash too. A bye for a model that failed would make every TUI wait for a daemon nobody starts. **Enforced** for the client's reading by `TestBye_LossAfterItIsGraceful` and `TestLoss_WithoutByeIsNot`; **Convention** for the daemon's fatal path sending none, since `TestServe_StopsWhenTheModelIsGone` (`internal/daemon/serve_test.go`) checks its exit, not its frames.
- **After `Server.Bye`, take no request or cast, let the calls already in finish and publish their replies, and close last (`Server.Close`).** A close before those jobs land loses their replies, and a TUI keeps showing the pause as Loading; `Bye` counts the calls it let in so the daemon's quiesce waits for every job they started. **Enforced** by `TestBye_WaitsForTheCallsItLetIn`, `TestBye_WaitsForTheRepliesOfTheCallsItLetIn`, `TestBye_TheServerRefusesARequestThatCrossedIt` and `TestBye_InFlightReplyArrivesBeforeClose`.
- **Add a frame field only as optional, and keep `bye` ignorable.** An older client decodes past an unknown field and its read loop falls through on a frame that matches nothing it reads; no `Protocol` bump while that holds. **Enforced** by `TestClient_IgnoresAnUnknownFrameField`.

### Replica and tests

- **Let the replica ignore a `ViewsChanged` for a workspace it doesn't hold.** A coalesced `WorkspacesChanged` that dropped a workspace can arrive ahead of a views event queued for it, which would otherwise bring the dropped workspace back for good. **Enforced** by `TestReplica_IgnoresViewsOfAWorkspaceThatIsNotLoaded`.
- **Have whatever serves a loop begin it (`Loop.Begin`); `InProcess` does so once its client has dialled.** A loop that never began never ticks, so no session dies, no diff changes and no account refreshes. **Enforced** by `TestInProcess_BeginsTheLoop`, which waits for a tick; the order after the dial is **Convention**, since the notice backlog keeps a notice published before any connection.
- **Test this package with production (non-synchronous) clients, and compare times that crossed the wire as `time.Now().Round(0)` values.** A synchronous client (`InProcessForTest`, which `app`'s tests use) pings before every read and hides ordering bugs, and JSON drops the monotonic reading that `assert.Equal` compares. **Convention** — tests that pass against behaviour the TUI never sees.
