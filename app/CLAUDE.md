# app

The Bubble Tea TUI: views, key routing, overlays, the workbench and the Lua script host, over a `core.Core` client of the daemon whose replica it reads and whose model it changes only by request. Full reference in [`README.md`](README.md).

## Rules when modifying this package

### Threads and state

- **Never mutate shared state or read `m.*` in a `tea.Cmd` body.** Bubble Tea runs each Cmd on its own goroutine, concurrent with `Update`/`View`, and the slot fields resolve through the embedded focused slot that `loadSlot` swaps, so the read races or reaches the wrong workspace after a switch. Capture what the Cmd needs on Update, and resolve the panes it reads there (`statusDetectCmd`'s argument, `snapshotScan`'s targets). **Convention** — races only `CGO_ENABLED=1 go test -race` finds.
- **Hold no model object.** `app/`, `ui/` and `script/` hold copies (`core.InstanceView`, `core.WorkspaceView`) and change the model only by request; the TUI reaches tmux by session name (`tmux.NewSessionNamed`, `m.sessionAlive`), never through an instance. **Enforced** by `TestTUIHoldsNoModelObject` (`internal/testenv/instance_enforce_test.go`).
- **Decide from the cached stores, never by combining two live queries.** `rpc:local` queries read the client's replica, which its reader updates as events arrive, so a job's result can land between two reads in one Update; `slot.views` and `slot.info` change only at a drain. Treat accounts, GitHub and the registry as display data and leave the rest to the request, which re-validates (`admit`). **Convention** — a decision made on a state that never existed.
- **After a request whose pre-step changes the model, call `syncViews` before reading rows.** The replica holds the change when the request returns, since a request's events arrive before its reply, but the slot stores catch up only at the drain: a kill's Deleting or a create's row shows one Update late. **Enforced** by the mutation-pinned tests in `app/views_freshness_test.go`.
- **Re-read a view kept past its Update by ID before acting on it** (`viewByID`, `viewBySession`). The split pane's and menu's copies, a Cmd's argument and the script host's snapshot follow nothing; `refreshSelection` repoints the split pane and menu on every store or overlay change. A deliberate snapshot is safe only when its request re-validates it (`pendingMergeSourceItems`, checked by `Merge`'s `admit`). **Convention** — an action on a row as it was.
- **Drain right after a model call whose events the next steps depend on.** Events apply at the end of `Update` (`drainCore`), so `openTab`, `enterGlobalMode`, `restoreSavedWorkspaces` and `startHome` drain after `Core.Open`, and the open's notices land before the recovery summary. **Convention** — notices and views arrive after the code that needed them.
- **Never read back a cast's effect.** A cast (`SetSelected`, the pane triggers, `WatchGitHub`) has no reply and the server publishes nothing after one; anything the TUI reads back must be a request. **Convention** — a read that sees the old state until some later publish.
- **Never `Send` from Update's own handlers.** `tea.Program.Send` blocks until Update returns, so only the output pump and timer goroutines send. **Convention** — a total UI freeze.

### Acting on instances

- **Act on the `InstanceID` captured when the key's gate passed, never the selection or a list position.** The user can move the selection, switch workspace or open a flow while a kill or start runs, and an ID names one record (a record recreated under a killed title has a new `created_at`, so a new ID), so a stale one is refused (`ErrNoSession`) instead of hitting whatever took its place. A creation flow is a `draft` until `confirmDraft` sends `Create`, and every cancel path calls `discardDraft`, with nothing to kill. **Enforced** for today's paths by `TestCreationCancelPaths_KillThePendingInstanceByIdentity`, `TestDiscardDraft_NeverKillsAStartedInstance` (`app/flow_selection_test.go`) and `TestRunMergeSelected_TargetSurvivesConcurrentSelectionChange` (`app/merge_test.go`); **Convention** for a new one — an action that lands on another session.
- **Give every user-started lifecycle request a `ReqID` (`opReq`).** With 0 a refusal is only logged (`request.refused`); `refusal()` shows a Reply's error only when it matches `core.ErrRefused`, since a failed job is the model's to show as a notice. **Enforced** for kill, merge and send by `TestRefusal_…` (`app/requests_test.go`); **Convention** for pause, resume, push, recover and any new key — a refused key that silently does nothing.
- **Let a completion act on the workspace stamped at dispatch, and on the focus UI only for this client's own request.** `applyStarted`/`applyRecovered` select the row, attach inline or notify only when `Req` is non-zero; another client's completion only gets its pane attached, an owner no open slot shows attaches nothing, inline attach needs a row still `Active()`, and the focused slot's selection moves only in `stateDefault`. **Enforced** by `TestInstanceStarted_…` (`app/async_owner_test.go`) and `app/flow_selection_test.go`.
- **Hold input to an instance while a prompt send to it is in flight** (`sendPrompt`, `holdInput`, `m.sending`). Until its Reply, `sendingTo` refuses inline attach and another send with an info line (the prompt overlay keeps its text), so typed keys can't land between the paste and its Enter; Lua's `send_prompt` holds too. **Enforced** by `TestSendHold_…` (`app/requests_test.go`) and `TestScriptSendPrompt_HoldsInputUntilTheReply` (`app/script_requests_test.go`).

### Workspace slots

- **Change focus only with `loadSlot`, and restore `checkSlotInvariant` before every `m.slots` mutation returns.** `loadSlot` runs `leaveFocusedSlot` (workbench cleanup and the pending split-ratio flush) on the departing slot; `enterGlobalMode`, and `openTab` when the first tab leaves classic mode, leave by another route, so they call it first. Never "switch" by editing the focused slot: a slot shows one `WorkspaceID` for its life. **Enforced** by `TestSlotInvariant_…`, `TestCloseFocusedTab_FlushesPendingRatiosIntoItsState`, `TestEnterGlobalMode_FlushesPendingRatiosIntoTheTabsState` and `TestStartupPicker_FlushesPendingRatiosIntoClassicState` (`app/workspace_slot_test.go`).
- **Show a workspace only through `Core.Open`, and never load, save or drop one in the model.** The model serves every registered workspace whatever the TUI shows; which tabs are open, the startup workspace, `failedOpen` and `home.program` are the TUI's own state, persisted through `Core.PersistOpenList`. Refuse a name whose directory the model serves under another (`servedFor`, `sameDir`), since tabs, the picker and the open list key on names. **Enforced** for the refusal by `TestActivateWorkspace_ARenamedWorkspaceIsRefused` and `TestActivateWorkspace_ASecondNameForOneDirectoryIsRefused`, and for never dropping by `TestSlotInvariant_HoldsAcrossSlotLifecycle` and `TestReopenedTab_IsTheSameWorkspace` (`app/workspace_slot_test.go`); **Convention** for a new transition that loads or saves — a workspace the model serves twice, or a save that overwrites the daemon's.
- **When a slot is dropped, return `prunePanes` and `releaseSlotCmd` and run `instanceChanged`.** The prune closes clients no open slot's active row needs, the release detaches the slot's terminal-pane clients without killing their shells, and `instanceChanged` stops the panes and menu keeping a dropped row; only rows an open slot shows get repaired. **Enforced** by `TestDroppedSlot_…` (`app/slot_release_test.go`).

### Pane clients

- **Close a pane client only after `Retain` or `Replace` removed it from the registry, and off the Update goroutine.** A release waits for the output pump, which blocks in `tea.Program.Send` until Update returns, so `releaseClientsCmd` runs `PausePreview` in a Cmd. Kill and pause have no TUI step: the completion's `core.ClientsStale` triggers the prune. **Enforced** by `TestKillAndPause_CloseTheClientOnlyAfterTheRegistryDrops` (`app/panes_test.go`) and `TestPrunePanes_ReleasesOnlyInactiveSessions` (`app/slot_release_test.go`).
- **Key a client by the view's `TmuxSession` and take its adapter from `SessionProgram`, never `Program`.** A resume that reattaches a live session (`R` with a new program) keeps the old session while `Program` already names the new one. Only an `Active()` row gets a client, and every attach point (`ensureSlotPanes`, `replacePane`, `ensurePane`) runs on Update. **Convention** — trust and pending-prompt patterns of the wrong program.

### Periodic work and status

- **Put per-instance periodic work on the health tick: the model's half (`core/tick.go`) when it needs no pane client, the TUI's (`tickUpdateMetadataMessage`) when it does.** With the emulator there is no preview tick; react to output through the pane event messages (`app/events.go`). **Convention** — work that never runs, or a poll the event path was built to remove.
- **Make emulator-path status re-arm itself.** Quiet fires once per burst and the health tick runs no ladder, so an inconclusive detection (`updated=true`, or a quiet dropped while Loading) re-arms through `maybeRedetect`/`redetectMsg`; a rule waiting for "the next poll" latches (the old `updated→Running` latch). **Enforced** by `app/status_redetect_test.go`.
- **Keep the status ladder a display overlay.** `statusDetectedMsg`, `snapshotStatusMsg` and `paneDirtyMsg`'s Ready→Running promotion write only `m.ladder` (`setLadder`), shown by `overlay()` for an active row with no reported status and dropped by `pruneLadder`; a row with `StatusReported` leaves status to the model and skips `maybeRedetect`, and a pane with no client is no opinion. **Enforced** by `TestViewsChanged_PrunesTheLadderOfInactiveAndReportedRows` (`app/views_freshness_test.go`), `TestReportedStatusSuppressesRedetect` (`app/claude_status_test.go`) and `TestStatusDetection_NoClientGivesNoOpinion` (`app/events_test.go`).
- **Judge an inline-attached pane's liveness by the focused pane** (`focusedPaneAlive`). The agent and terminal panes are separate tmux sessions; checking only the agent's leaves keystrokes vanishing into a dead terminal frozen on "[exited]". **Enforced** by `app/state_inline_attach_terminal_death_test.go`.

### Overview and workbench

- **In overview, pass keys through `overviewKeyAllowed`, drop mouse input, and clear attention only on entering focus.** Anything else acts on the hidden focus layout or reshuffles the attention-sorted grid under the cursor. **Enforced** by `TestOverviewKeyWhitelist_BlocksFocusOnlyKeys`, `TestOverviewMouse_Ignored` and `TestOverviewBell_ClearedOnFocusNotGridCursor` (`app/overview_mode_test.go`).
- **Keep the overview cursor (`overviewData`), `moveCursor`/`fleetOrder` and `jumpWaiting` on the same classic-vs-slots split (`len(m.slots)==0`)**, reading every slot's list as `m.slots[i].list`. A stale cursor is healed by `normalizeOverviewCursor` at render and navigation; add no per-event cursor bookkeeping. **Convention** — navigation and render diverge.
- **Tear the workbench down only through `cleanupWorkbench`, and retarget the review only through `home.dropReviewPane`.** `leaveFocusedSlot` calls the first, so a switch can't leave the split's terminal hidden; `home.wbReview` and `Workbench.SetReview` must stay nil-iff-nil, or keys and `S`'s comments go to the previous session's pane. Run `SplitPane.SetSize` before `Workbench.SetSize`, since they share the terminal pane. **Enforced** for teardown and retarget by `TestWorkbench_SlotSwitchCleansUp` (`app/workbench_mode_test.go`) and `TestWorkbenchReview_RetargetDropsPane` (`app/workbench_review_test.go`); **Convention** for the `SetSize` order — a shared terminal pane sized for the wrong half.
- **Gate every synthetic key fed to the review pane on `Busy()`** (`reviewScrollKey`). A busy pane captures everything, so a wheel-fed key types into the comment modal. **Enforced** by `TestWorkbenchReview_ScrollIgnoredWhileModalOpen`.

### Keys, modal states and mouse

- **Adding a full-screen modal state?** Add it to `handleMenuHighlighting`'s exclusion list, or fast typing in its fields reorders characters ("toy" → "oyt"), and to `View()`'s overlay placement list if it draws through `m.activeOverlay`, or it takes keys while invisible. **Enforced** only for `stateSettings` by `app/menu_highlighting_settings_test.go` and for `stateIssuePicker` by `TestView_DrawsTheIssuePicker`; **Convention** for every other state, a new one included. Guide: [`../docs/claude/adding-a-modal-state.md`](../docs/claude/adding-a-modal-state.md)
- **Keep `ctrl+c` reserved in the default state, checked before the script engine.** A user script can unbind or shadow any other key, never the way out. **Enforced** by `TestCtrlCQuitsEvenAfterUnbind` (`app/state_default_ctrlc_test.go`).
- **Use `keys.KeyForString` only for menu highlighting, never to gate dispatch.** Dispatch is the script engine's (`HasAction`), so scripts can rebind a key without disturbing the menu. **Convention** — a rebound key that dispatches by the built-in table.
- **Gate mouse selection to `stateDefault` and `stateInlineAttach`, and offset hit-tests by `mouse.X - m.listWidth` and `mouse.Y - m.topChromeHeight()`.** Mouse messages reach Update in every state, and the account strip sits above the tab bar, so `tabBar.Height()` misplaces every selection by its row. In interact mode forward only plain clicks: tmux runs with `mouse on`, so a forwarded drag enters its copy-mode. **Convention** — selections offset or dead in a pane the user focused. Guide: [`../docs/claude/ui-geometry.md`](../docs/claude/ui-geometry.md)

### Scripts, late results, settings and shutdown

- **Keep `scriptHost` free of `*home`.** Script primitives record a `func(*home)` through `deferModelMutation`, applied in `handleScriptDone`; those moving the selection or focused slot use `deferFocusMutation`, applied only in `stateDefault`. Reads come from the snapshot `newScriptHost` takes on Update, and `ctx:new_instance` creates only while `scriptDoneMsg.slot` is still focused. **Enforced** by `TestScriptHost_SelectionIsDispatchTimeSnapshot` (`app/script_host_snapshot_test.go`) and `TestScriptDone_DropsInstanceWhenFocusChangedMidDispatch`, and under `-race` by `TestScriptHost_ReadsDoNotRaceUpdate`.
- **Drop a late issue result, with a message, when the focused repo or the flow changed.** A fetch can land long after the key, and applying it would let `openLaunchOptionsForNew` replace another flow's pending closure; `handleIssueExpanded` also drops a result whose draft is no longer `m.draft`. `handleIssuePicked` returns on a fetch error before its guards; `handleIssueExpanded` falls back to the literal prompt on error, so its guards run before its error branch. **Enforced** by `TestIssuePickedMsg_WrongRepoCreatesNothing`, `TestIssuePickedMsg_DoesNotClobberAnotherFlow` (`app/state_issue_picker_test.go`), `TestIssueExpandedMsg_WrongRepoDoesNotOpenHere`, `TestIssueExpandedMsg_DroppedResultReportsFetchError` and `TestIssueExpandedMsg_DoesNotClobberAnotherFlow` (`app/state_prompt_issue_test.go`).
- **Edit settings in a TUI-owned `config.Config` and save it whole.** The overlay edits `m.settingsEdit` (`config.FromSettings`) and sends `SaveSettings`, then rereads with `syncWorkspaces`; another TUI's change applies through `applySettingsChange` only when it changed. **Enforced** for another TUI's change by `TestSettingsChangedElsewhere_…` (`app/state_settings_test.go`); **Convention** for the save — a save that clobbers fields with stale values.
- **Read account warnings from the model, and reload accounts before a user-paced action reads them.** `CredentialOverride` and `RunningAsAccount` are the daemon's environment, never the TUI's; Launch Options, Settings and Accounts-screen requests call `ReloadAccounts` first, and `AccountsChanged` refreshes the views (`refreshAccountViews`). **Enforced** by `TestCredentialOverride_TheDaemonsEnvironmentDecides`, `TestRunningAsAccount_AClientConnectingLaterShowsIt` (`app/accounts_warnings_test.go`) and `TestReloadAccounts_SeesAnotherProcessesChanges` (`app/accounts_test.go`).
- **Go offline, never quit, when the client loses the model.** `Update` checks the link after its drain (`checkLink`, `app/link.go`), so a reply that arrived before the connection closed is applied, not failed as stranded: a bye takes the TUI to stopping, the loss to waiting (after a bye) or reconnecting; offline it fails every stranded request (`failStranded`), gates keys (`offlineKeyAllowed`) and rejoins (`Rejoin`, `resync`). Only a newer daemon ends it (`ErrDaemonNewer`, kept in `home.exitErr`, which `Run` returns). `handleQuit` saves no session (only split ratios and the open list), since saves are the daemon's. **Enforced** by `TestDaemonGone_GoesOffline` (`app/daemon_client_test.go`), `TestLink_ARepliedRequestIsNotStranded` for the order, `TestLink_…` (`app/link_test.go`), `TestReconnect_…` (`app/reconnect_test.go`) and `TestHandleQuit_SavesNoSession` (`app/app_test.go`).
- **Close the client `Run` holds through a closure (`defer func() { h.stopCore() }()`), never a method value taken at the `defer`.** A rejoin replaces `home.conn` and `stopCore` (`resync`), so a value taken at `defer` time closes the first client at return and leaks the last one and its wakes goroutine. **Convention** — a leaked connection per rejoin that no test observes.
- **A new key that needs the model stays off `offlineKeyAllowed`, and a new modal's commit carries a `ReqID` (`opReq`).** The gate covers only the default state's keys; an overlay open when the link dropped commits a request that the client refuses itself (`core.ErrUnavailable`), and with ReqID 0 that refusal is only logged. **Enforced** for today's keys by `TestOfflineKeyGate` (`app/link_test.go`); **Convention** for a new key and a new modal's `ReqID` — a key that dispatches into a refusal, or a commit that silently does nothing offline.

### Test harness

- **Build fixtures as production does.** Call `wireCore` after the slots are assembled and before exercising them; call `m.syncViews()`/`m.syncWorkspaces()` after changing the model outside an Update; deliver results with `deliver`/`pumpCore`, wrapping one as this client's own with `core.CausedForTest`. **Convention** — a test reading views from before the change, or a completion treated as another client's.
- **Compare times that crossed the wire with `time.Now().Round(0)`.** The wire drops the monotonic reading, which `assert.Equal` compares. **Convention** — a spurious failure.
- **Keep fake PTYs from `internal/testpty` open, and keep tests off the developer's tmux server.** A `/dev/null` PTY reads EOF at once, which a client takes for a dead session; `TestMain` points `LOOM_TMUX_SOCKET` at a private server and real-tmux tests call `isolateTmux`. **Convention** — clients that never attach, or a test that kills real agents.
